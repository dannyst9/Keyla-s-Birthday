# Birthday Card

Proyecto de Codex para desarrollar tarjetas de cumpleaños a partir de las referencias visuales del chat original **“Crear proyecto Birthday Card”**.

## Dirección visual inicial

- Collage y scrapbook
- Fotografías tipo Polaroid
- Texturas de papel y recortes
- Tipografía experimental
- Humor y memes de cumpleaños

## Recursos

Las imágenes recuperables del chat se copiaron en `assets/references/`.

- Referencias recuperadas del chat original: 10 archivos PNG (9 imágenes únicas; dos adjuntos son idénticos)
- Referencias añadidas después: 2 imágenes para el momento “Mi vida antes/después de conocerte”
- Referencias mencionadas originalmente: 11
- Pendiente: volver a adjuntar la imagen que la plataforma no expuso al recuperar el chat

## Origen

- Conversación: `Crear proyecto Birthday Card`
- ID de conversación: `6aef8eb8-4bbc-83e9-aecf-5c6fc7f5e9cf`

La conversación original no se elimina ni se mueve físicamente. Este proyecto conserva una copia local de los recursos que la plataforma permitió recuperar y un resumen del contexto creativo.
